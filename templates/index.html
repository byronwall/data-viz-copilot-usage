What am I looking at?

This viewer charts your Copilot chat sessions — every request, sub-agent, and compaction — so you can see where tokens and cost (AIC credits) go. Below is a live demo session: one main agent that spawned two sub-agents. Everything here is interactive.

1 · Anatomy of a chart

Each card is one session. The big band plots cumulative input tokens over time; the band below it plots per-turn input. Hover a number to locate it on the chart.
